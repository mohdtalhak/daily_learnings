# 📓 daily-learnings

A running log of what I debug, build, and figure out — one entry a day, added to that month's file.

## 📂 Structure

```
daily-learnings/
├── README.md
├── 2026-07.md
├── 2026-08.md
└── ...
```

One file per month. Each day is just a new dated section appended to the bottom of that month's file.

## ✍ How I use this

1. Open this month's file (create a new one if it's the 1st, e.g. `2026-08.md`)
2. Paste this at the bottom:

```
## 2026-08-01

**Worked on:**
-

**Debugged / broke:**
-

**Learned:**
-
```

3. Fill it in — even 2-3 short lines is enough
4. Commit + push

```bash
git add .
git commit -m "log: 2026-08-01"
git push
```
